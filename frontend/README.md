# 🎨 TeenSpend Frontend (React, Vite & Recharts)

## Structure
- `src/components/`: Reusable UI elements (Navbar, Sidebar, Charts, Cards, ProtectedRoute)
- `src/pages/`: Application views (Login, Register, Dashboard, Expenses, Budgets, Analytics, Suggestions, Profile)
- `src/services/`: Axios HTTP client and API endpoints
- `src/context/`: AuthContext managing user sessions and JWT
- `src/hooks/`: Custom `useAuth` hook
- `src/utils/`: Currency and date helpers
- `src/index.css`: Modern teen-friendly design system (Glassmorphism, Dark UI, Responsive)

## Running the Dev Server
```bash
npm install
npm run dev
```

App loads at `http://localhost:5173`.
